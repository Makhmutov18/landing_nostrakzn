# Nostra templates

Шаблоны демонстрируют композицию и иерархию. Перед публичным использованием:

- заменить текстовое имя партнёра официальным векторным логотипом;
- проверить разрешение правообладателя;
- обновить коммерческие данные по `../claims.json`;
- не изменять цвет и пропорции партнёрской марки;
- не использовать co-branding-шаблон как этикетку или маркировку продукта.

## Файлы

- `cobrand-tasty-template.svg` — partner-first схема для Tasty Coffee;
- `cobrand-herbarista-template.svg` — partner-first схема для Herbarista;
- `data-card-tasty-35.svg` — подтверждённый коммерческий факт;
- `kp-cover.svg` — базовая обложка коммерческого предложения.
