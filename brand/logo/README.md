# Nostra logo assets

## Файлы

- `nostra-wordmark-primary.svg` — основной графитовый wordmark на светлых поверхностях.
- `nostra-wordmark-reversed.svg` — светлая версия на графитовом или бордовом фоне.
- `nostra-wordmark-oxblood.svg` — акцентная версия для редких самостоятельных применений.
- `nostra-monogram-primary.svg` — сокращённый знак для favicon, аватара и малых digital-слотов.

## Статус

Это production-ready векторная геометрия: wordmark собран путями и не зависит от наличия шрифта. Запрещено растягивать, наклонять, менять межбуквенный ритм или перекрашивать отдельные буквы.

Официальные логотипы партнёров не входят в этот набор. Их следует получать у правообладателей и помещать в co-branding-шаблон без перерисовки.
